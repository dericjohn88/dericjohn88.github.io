GitHub Pages Migration

API hosting, project notes, and status reporting without the Wix runtime.

This site is the static translation of the original dashboard shell. It keeps the dashboard view, tool registry, and endpoint inventory in plain HTML, CSS, and vanilla JavaScript so it can live directly in GitHub Pages.

Current surface

  • Static project dashboard
  • Tool health snapshot
  • Endpoint inventory
  • GitHub-native hosting

Overview

Hosted tool registry

The original Wix embed generated these cards dynamically. This version keeps the same information architecture in a static site that can be extended without platform-specific dependencies.

Applications

Current tools

Select a tool to inspect its status, ownership, and endpoint layout.

Hosting

Static deployment notes

The Wix-specific owner login gate and backend `.jsw` calls are intentionally not reproduced here. GitHub Pages is now the presentation layer, while protected runtime features can move behind separate services as the hosting strategy evolves.

Frontend

Plain HTML, CSS, and JavaScript

No framework build step is required for this repository. The page is ready to publish directly from the default branch.

Auth

Decoupled from hosting

The old Google + Wix Members gate was platform-bound. Any future authentication should live in a dedicated service, not the static site layer.

API Docs

Endpoint inventory retained

The current tool cards and detail panel still expose the endpoint structure so the site can serve as a lightweight operational reference.
