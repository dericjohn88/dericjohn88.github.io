# dericjohn88.github.io

Static GitHub Pages version of the former Wix-hosted API dashboard.

## Structure

- `index.html`: main landing page and tool dashboard shell
- `styles.css`: site styling translated from the Wix embed theme
- `app.js`: lightweight client-side rendering for tool cards and detail view

## Notes

- The Wix-only owner login flow was not carried over because GitHub Pages is static hosting.
- The site now acts as a public-facing project and endpoint overview that can be extended with additional tool entries over time.
